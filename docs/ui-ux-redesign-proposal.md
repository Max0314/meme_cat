# Cat Meme Studio UI/UX 重构方案

## 目标

把当前工具从“功能都在但挤在一起”调整为“围绕剪辑任务流展开”的工作台。核心目标是：素材好找、拖放可预期、预览可信、轨道不混乱、右侧只显示当前需要调整的参数。

## 信息架构

主界面采用五区结构：

1. 顶部项目栏：项目名、画幅预设、保存、新建、预览、导出。
2. 左侧素材库：本地素材、收藏、最近使用、场景分类、猫 meme、音频、道具。
3. 中央剪辑区：预览画布、播放控制、快速字幕、片段信息。
4. 底部时间线：播放头、标尺、轨道、片段块、缩放、轨道显隐锁定。
5. 右侧检查器：随选中对象变化。选中素材片段显示变换/抠像/音量；选中字幕显示文字样式；未选中时显示项目状态和导出检查。

## 素材库

素材库改成“分类导航 + 搜索过滤 + 虚拟网格 + 分页/批量操作”。

左侧分类：

- 全部
- 背景场景
- 角色绿幕
- 音频素材
- 特效/道具
- 字幕/贴纸
- 收藏
- 最近使用

背景场景分类按现有目录展示：办公室、城市、窗口、古风、建筑内、建筑外、教室、街道、实景--办公室、实景--车内、实景--城市、实景--地铁 公交车 车站、实景--学校、小院、学校、野外。

素材卡交互：

- 单击：选中并在右侧显示素材详情。
- 双击：投放到当前播放头。
- 拖到预览：从当前播放头开始，按素材类型自动进入轨道。
- 拖到时间线：仍然从当前播放头开始，鼠标位置只决定投放目标轨道。
- 鼠标悬停视频：只播放低频预览帧，不自动加载所有视频。
- 收藏：固定到角色推荐和常用区。

性能策略：

- 只渲染可见素材卡。
- 视频缩略图使用封面缓存，不让列表里几十个 video 同时解码。
- 搜索使用 debounce，分类统计使用 memo/cache。
- 分页保留，但默认无限滚动；用户也可以跳页。

## 视频编辑区

预览画布保留在中央，旁边不再塞满表单。画布上只放必要控制：

- 顶部：画幅标签、当前帧、适配/100%/全屏。
- 画布内：选中图层的边框、缩放点、旋转点、对齐参考线。
- 下方：播放、前后帧、倍速、快速字幕输入。

视觉规则：

- 背景素材默认铺满画面，并放在最底层。
- 多个背景按添加顺序叠放：先加在下，后加在上。
- 角色绿幕保持素材自身比例，不跟随横屏/竖屏拉伸。
- 选中画面元素后，右侧显示 X/Y、缩放、旋转、翻转、透明度、抠像。

## 时间线

时间线改成“固定轨道头 + 可滚动片段区”。

轨道分组：

- 背景：只放背景场景。
- 角色 1/角色 2/角色 3：放猫 meme 绿幕。
- 道具/特效：放贴纸和视觉特效。
- 字幕：放字幕块。
- 配音、BGM、音效：放音频。

轨道交互：

- 轨道头固定，横向滚动时不丢失轨道名。
- 每条轨道有显隐、锁定、音量/静音。
- 片段块显示名称、长度、入点、有声标记。
- 拖动片段移动时间；拖动边缘裁剪；Alt 拖动复制。
- 背景素材不能拖到角色轨道，角色素材不能误进背景轨道。
- 播放头吸附片段开头、结尾和字幕边界。

## 右侧检查器

右侧不再做“大杂烩”，改为上下文面板：

未选中：

- 项目状态
- 当前画幅
- 总时长
- 素材缺失检查
- 导出建议

选中视频/图片片段：

- 基础：名称、起始帧、时长、入点、音量。
- 画面变换：X、Y、缩放、旋转、翻转、透明度。
- 抠像：开启、颜色、相似度、边缘融合。
- 层级：置顶、上移、下移、置底。

选中字幕：

- 文本内容
- 字体、大小、颜色
- 描边颜色、描边宽度
- 背景开关、背景颜色
- 位置、对齐、持续时间

选中音频：

- 音量、淡入淡出、起始点、波形预览。

## 核心工作流

1. 选画幅：顶部选择竖屏/横屏。
2. 找背景：左侧背景场景分类，双击投放到当前播放头。
3. 找猫 meme：切到角色绿幕，拖到预览画布，自动保持比例。
4. 调画面：直接在预览画布拖动，右侧微调参数。
5. 加字幕：底部快速字幕输入，右侧样式统一配置。
6. 调时间：底部时间线裁剪、复制、错位、吸附。
7. 导出检查：右侧显示是否缺素材、是否有空白片段、是否音量过高。

## 交互优先级

第一阶段：

- 重构三栏布局和固定底部时间线。
- 素材库虚拟列表、分类、搜索、分页。
- 背景/角色/音频自动轨道规则。
- 右侧检查器上下文切换。

第二阶段：

- 画布拖拽缩放旋转控件。
- 时间线吸附、复制、批量选择。
- 收藏、最近使用、角色推荐。

第三阶段：

- 素材缩略图缓存。
- 波形缓存。
- 导出前质量检查。
- 模板化片段编排。

## 2026-11-18 实现校对

- 现有浅色工作台继续保留，新增顶部月亮/太阳按钮切换并保存深色模式；标题栏、工具、素材区和检查器使用对应主题颜色，视频画面和字幕自身颜色不随主题改变。
- 收紧窗口时允许中央列收缩，低高度窗口重新分配预览与时间线空间；补充键盘焦点样式和未保存状态。
- 时间线分类只筛选轨道；预览保持完整合成，只有显式独奏/静音改变预览范围。角色状态原声也遵守独奏。
- 增加新建/打开/关闭前的应用内保存提醒，失败时保持当前工程；保存快捷键在文本输入中可用。
- 收藏/使用素材不再重置分页；查询、分类、类型、来源和排序变化仍回到第一页。
- 顶部恢复“AI 与模板”侧栏：主题/风格/时长生成可编辑脚本草稿，确认后应用；可手写工程脚本；配音选择文本、声音后按实际时长加入播放头，保留旧配音；模板选择素材后使用新轨道插入分镜与字幕，整体可撤销。未应用草稿只保留在本次会话，界面已有说明。
- 模板素材支持搜索，每次最多显示 60 个匹配项，保留选择顺序；外部素材先复制。模板与手写脚本不要求 AI 凭据。AI 请求期间抑制重复调用，跨工程响应不覆盖当前工程。
- 目前素材库使用分页，不是虚拟滚动或默认无限滚动；上方路线中未实现的内容仍是设计建议。
- 本次只进行了源码、Node 行为回归与构建验证，没有打开本地应用进行视觉验收。
